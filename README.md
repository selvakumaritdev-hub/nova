# NOVA MALL (one project)

    npm install
    npm run dev

- Shop (customers):    http://localhost:5173
- Admin (owner only):  http://localhost:5173/admin   (no link in the shop, type the URL)

Windows: double-click START.bat

Admin shows live orders, customers, products, activity (login, signup, cancel, return).
Open an order to update its status (Packed, Shipped...) - customers see it in their order tracking.
Sample data is pre-loaded; use "Clear all data" on the dashboard to start fresh.
